Skyrim Assets Catalog

Assets catalog for TESV: Skyrim

Motivation

When playing Skyrim, sometimes I like to decorate the game world by placing more objects in it. I already use a mod for crafting and placing pieces of furniture, but I still have to find a practical mod to place "static" objects. I ended up having to get the base form ID for these objects and placing them manually via the console command player.placeatme, but getting these IDs was not easy. I searchd if there was some kind of catalog online mapping these IDs with the static objects, but I didn't manage to find one. I decided to build a mostly automated pipeline to map the IDs to image renderings of the statics objects and set up this public website for such a catalog.

Why screenshots?

I think screenhots serve the purpose good enough for the catalog (i.e. be a simple informative website). Uploading the complete NIF files and their respective textures might be a bit too much and could call bad attention from Bethesda, I guess. If you own the game, extracting the files and using NifSkope or using the Creation Kit to view them individually is always an option.

Future plans

Might add some other object types to the catalog.
